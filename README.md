# ALSCIF Oilfield Converter Pro

Offline-capable PWA: unit converter, coiled tubing calculations and job report.

## Publish
1. Upload every file in this folder to a GitHub repository (keep the `icons` folder).
2. Settings > Pages > Branch `main`, folder `/ (root)` > Save.
3. Open `https://USERNAME.github.io/REPO/`.

## Install
- iPhone: open in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu > Install app.

When you change `index.html`, change `alscif-v1` in `sw.js` to `alscif-v2` so devices refresh.
